# Suivi public des engagements

> Proposition issue du programme municipal pour la ville du Blanc-Mesnil.

## Catégorie

Gouvernance, éthique et exemplarité

## Description

Mettre en place une Plateforme de Suivi des Engagements (PSE) — un tableau public en ligne pour chacune des 213 mesures du mandat. Chaque mesure affiche son statut (à faire / en cours / livré), le responsable, les dates et la Definition of Done co-construite avec les habitants.

Dès la mise en ligne, une consultation est lancée : « C'est quoi une mesure réussie pour vous ? ». Chaque Blanc-Mesnilois peut proposer ses critères de réussite. L'objectif est d'avoir la Definition of Done de chaque mesure co-construite avec les habitants avant la rentrée scolaire.

## Fiche détaillée

**Priorité** : A — Impact immédiat (0–12 mois)

| | |
|---|---|
| **Besoin identifié** | Les habitants n'ont aucune ou peu de visibilité sur l'avancement des promesses de campagne. |
| **Action** | Déployer un tableau public en ligne (et en mairie) pour chacune des 213 mesures. Lancer une consultation : « C'est quoi une mesure réussie pour vous ? » — co-construction de la Definition of Done avec les habitants.|
